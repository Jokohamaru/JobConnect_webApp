## ⚡ Quick Actions

### Start Backend
```bash
cd backend
npm run start:dev
```

### Test API
```bash
# Public endpoint
curl http://localhost:3000/companies

# Admin endpoint (cần token)
curl http://localhost:3000/admin/companies/stats \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Read Documentation
```bash
# Main README
cat README_COMPANY_MODULE.md

# Quick start
cat QUICK_START.md

# API reference
cat backend/src/modules/company/COMPANY_API.md
```
